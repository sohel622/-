## ফাইলগুলো

- `pubspec.yaml` — অ্যাপের নাম আর দরকারি লাইব্রেরি (http, image_picker, shared_preferences)
- `lib/main.dart` — পুরো অ্যাপ: চ্যাট UI, ডেমো মোড, ছবি বাছা, Settings
- `lib/api_service.dart` — API-কে ডাকার আলাদা ফাইল

## কী কী পারে

- বাংলায় চ্যাট: হ্যালো, নাম, কেমন আছো, সময়-তারিখ, জোক, সহজ হিসাব
- ছবি দিলে ছবি দেখায়, API থাকলে ছবি পড়ে বাংলায় বলে এতে কী আছে
- API key না থাকলেও চলে — তখন ডেমো মোডে ছোট উত্তর দেয়
- API key থাকলে আসল AI-এর মতো উত্তর দেয়

## APK বানানো — GitHub থেকে, কম্পিউটার ছাড়া

1. GitHub-এ রিপো খুলে **Actions** ট্যাবে যাও।
2. বামে **Build APK** বেছে **Run workflow** চাপো।
3. ৫-১০ মিনিট অপেক্ষা করো, সবুজ টিক এলে রানটা খুলো।
4. নিচে **Artifacts** থেকে **juno-mini-apk** ডাউনলোড করো, ভেতরে `app-release.apk` থাকবে।
5. ফোনে APK ফাইলটা খুলে Install চাপো। ফোন "অজানা অ্যাপ" বলে সতর্ক করলে Allow দিও।

প্রতিবার `main`-এ কোড পুশ করলেই APK নিজে নিজে বানানো শুরু হবে।

## চালানো — কম্পিউটারে

ফোনে সরাসরি Flutter চালানো যায় না, কম্পিউটার লাগবে।

1. কম্পিউটারে Flutter install করো (flutter.dev থেকে)
2. এই ফোল্ডারে গিয়ে চালাও:
   ```
   flutter pub get
   flutter run
   ```
   ফোন USB দিয়ে লাগিয়ে Developer Mode অন করে `flutter run` দিলে ফোনেই অ্যাপ চলবে।
3. APK বানাতে:
   ```
   flutter build apk --release
   ```
   APK পাবে `build/app/outputs/flutter-apk/app-release.apk` — সেটা ফোনে install করা যায়।

## API key — খুব জরুরি

- চ্যাটে পাঠানো পুরোনো key আর ব্যবহার কোরো না। যেখান থেকে key নিয়েছো, সেখানে গিয়ে ওটা delete করে **নতুন key** বানাও।
- নতুন key অ্যাপ খুলে উপরে ⚙️ Settings-এ লিখো। key ফোনেই থাকবে, কোডে যাবে না।
- Settings-এ আরও দুটো জিনিস আছে:
  - **Base URL** — Meta হলে `https://api.meta.ai/v1`, Model `muse-spark-1.3`
  - অন্য কোম্পানির API হলে তাদের ডকসে দেওয়া Base URL আর Model বসাও।
- এখনো জানা যায়নি তোমার key কোন কোম্পানির। শুধু নামটা বলো — Meta, OpenAI, Google Gemini, নাকি অন্য কিছু — তাহলে আমি Base URL আর Model ঠিক করে দেবো।
